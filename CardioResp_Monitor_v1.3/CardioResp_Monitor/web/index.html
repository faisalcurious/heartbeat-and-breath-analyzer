          Display and alarms

          Theme

          Auto follows the phone or computer setting. Dark is easier on the eyes at night and saves battery on OLED screens. The choice is remembered on this phone.

          Alarm sounds

          OnAlarm, when it starts, and its sound
          --
          Without a valid licence the "heart signal lost" and "cough / vibration" alarms are not available. The other alarms keep working.
          Each kind of alarm has its own sound. Urgent alarms repeat every 4 s, warnings every 10 s, notices every 20 s. Safety alarms (heart signal lost, breathing pause, sensor lost, no data) cannot be switched off one by one. Sound plays only after the page has been tapped once, and only while this page is open with the screen on. Silence on the alarm bar mutes the current alarms for 2 minutes; a new alarm, an alarm that comes back or one that gets worse still sounds. Switching all alarm sounds off lasts until the page is opened again.

          Calibration

          Sensor calibration (gravity reference)

          Recalibrate after fixing the sensor again or after a large change of posture. The person must keep completely still for about 8 seconds while the monitor measures gravity. (Start measurement on the Live page always calibrates first.)

          Accelerometer calibration (6 positions)

          Only needed when the start-up check reports a gravity reading far from 1.00 g. Take the sensor off the body, rest it on a flat table and capture each of its six faces pointing up (both flat sides, both long edges, both ends). Keep it untouched for 2 s per capture.

          Body temperature calibration

          The sensor reads its own chip temperature. Enter a reference thermometer reading while the sensor is on the skin and the monitor will correct the offset.

          Mesh network

          Mesh settings

          Monitors share their patients with each other over a short-range radio link; no router is needed. Only monitors with the same group name and PIN are accepted: every message is signed with them.

          Use the same group name and PIN on every monitor that should share data. Relay hops let monitors pass on messages from monitors further away. All monitors must use the same Wi-Fi channel.

          Verify nearby monitors

          Asks every monitor in radio range to answer and lists them. Verified monitors share data with this one; the others need the same group name and PIN.

          Power, network and system

          Power and heat mode

          Lower modes run the processor slower and send less data, so the monitor stays cooler and the battery lasts longer. The monitor also steps down by itself when it is hot, and boosts for a few minutes if the analysis falls behind.

          System

          Restart and reset

          Restart the monitor

          Switches the monitor off and on again. Settings, recordings and the licence are kept. A measurement that was running starts again by itself.

          Factory reset

          Erases the Wi-Fi network, age, calibrations, temperature offset, power mode, mesh settings, patient and nurse profiles and all recordings, then restarts. The licence (activation key) is kept.

          Licence and firmware

          Licence

          The key is bound to this monitor's MAC address and has an expiry date. Without a valid key only heart rate, breathing rate and the sensor placement are shown.

          Firmware update

          Choose the update file (.bin) you received from the supplier. The monitor restarts when the upload finishes. Keep the phone close to the monitor and the monitor on power.

          This monitor

          CardioResp is a research and wellness instrument based on seismocardiography (chest vibration) and chest-wall motion. It is not a certified medical device and does not replace ECG, pulse oximetry or clinical assessment. Results depend on sensor contact and stillness. Share the report with a qualified clinician for interpretation.
